# ieee754
## Описание
Данный проект представляет собой программную реализацию арифметики с плавающей запятой на C++. Вычисления производятся исключительно с использованием целочисленных типов (`uint32_t`, `uint64_t`) и побитовых операций, без использования аппаратного FPU.

## Ключевые возможности 
* **Кастомная точность:** количество бит, выделяемых под экспоненту и мантиссу, задается через параметры шаблона (можно эмулировать Float32, Float16 или другие нестандартные форматы).
* **Полная поддержка краевых случаев:**
  * Корректная обработка **денормализованных чисел** (Subnormals).
  * Поддержка **NaN** (Not-a-Number) и **Infinity** (Бесконечность).
  * Обработка знакового нуля (`+0` и `-0`).
* **Настраиваемое округление:** поддержка различных режимов округления в зависимости от конфигурации (round-to-nearest, round-to-zero и т.д.).
* **Арифметические операции:** 
  * Базовые: Сложение (`Add`), Вычитание (`Sub`), Умножение (`Mult`), Деление (`Div`).
  * **FMA:** выполнение операции `(a * b) + c` с однократным округлением для минимизации потери точности.
  * **MAD:** стандартное `(a * b) + c` с двойным округлением.
* **Форматированный вывод:** функция `Print`, выводящая число в точном шестнадцатеричном представлении (в формате C++11 hexfloat: `0x1.mantp+exp`).
